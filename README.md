# MegaCapacetes

Loja virtual de capacetes, peças e acessórios para motocicletas, com identidade visual em azul e branco.

## Tecnologias

- Next.js / Vinext
- React e TypeScript
- Cloudflare Workers
- Drizzle ORM

## Desenvolvimento local

Requisitos: Node.js 22.13 ou superior.

```bash
npm ci
npm run dev
```

## Build de produção

```bash
npm run build
```
